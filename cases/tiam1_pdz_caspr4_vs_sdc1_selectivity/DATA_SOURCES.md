# TIAM1 residue evidence

`residue_evidence_catalog.json` contains the case's derived, zero-based annotations for residues 841–930 of human TIAM1. The loader verifies its canonical content hash, `f09896cae059cb2298c0edb113e44c6acca63e20f307f0571a6e542cc4b4ac69`.

Solvent accessibility was calculated from the apo domain. The interface annotations count heavy-atom contacts within 4 Å in the Caspr4 and Syndecan-1 complexes. The Caspr4 structure uses a quadruple mutant and the Syndecan-1 structure uses wild type, so the contact difference includes a construct difference. The source coordinate data are available under CC0.
