# cAb-Lys3 reference inputs

The four A3M files under `inputs/msa_cache/` are frozen alignments from the project's ColabFold search for the original antibody and antigen. The case replaces the query row for each candidate and retains the aligned homologs and pairings. The accompanying manifest gives the record count and SHA-256 of each alignment. ColabFold's reference databases are available under CC BY 4.0. Credit goes to Milot Mirdita and the ColabFold team. [ColabFold database downloads](https://colabfold.mmseqs.com/) · [ColabFold paper](https://doi.org/10.1038/s41592-022-01488-1) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The SAbDab2 records in `inputs/sabdab_vhh_reference/` are from the Oxford Protein Informatics Group. The project selected 988 VHH reference records, separated their CDR and framework regions, and generated normalized ESM-2 embeddings, calibration statistics and a target profile for this case. The CSV retains the SAbDab2 and PDB identifiers. The embedding manifest records the pooling procedure, model hashes and matrix checksums. These derived reference data are distributed under CC BY 4.0. [SAbDab2 data and licence](https://sabdab.opig.stats.ox.ac.uk/downloads) · [SAbDab2 paper](https://doi.org/10.1093/nar/gkag1091) · [ESM-2 model](https://huggingface.co/facebook/esm2_t6_8M_UR50D) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The project supplies the residue evidence catalog used by its cAb-Lys3 case alongside these references.
